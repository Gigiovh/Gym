# Gym E-commerce 💪
 <img  src="https://github.com/Gigiovh/Gym/blob/main/img/loho.png" alt="logo" min-width="160px" max-width="160px" width="160px" align="right">
 
 <p align="left"> 
 <b>Magym</b> é uma academia futurista e de alto padrão, com design inspirado no personagem <b>Majin Buu</b>, do anime Dragon Ball.
 A proposta da academia é inovar no cenário fitness por meio de uma identidade visual moderna e tecnológica.
<br><br>
O projeto foi desenvolvido com o objetivo de divulgar a academia, facilitando a visualização e contratação de planos de mensalidade pelos clientes. Além disso, o site conta com uma loja online de suplementos e uma seção de notícias voltada ao universo fitness.

 
 </p>
